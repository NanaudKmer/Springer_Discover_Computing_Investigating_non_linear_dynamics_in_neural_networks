# Springer_Discover_Computing_Investigating_non_linear_dynamics_in_neural_networks
MATLAB code of the proposed medical image encryption scheme based on a diffusion–confusion–diffusion architecture, integrating DNA encoding and chaos-driven operations. Pseudorandom sequences are generated using a Tabu Learning Neuron model driven by external stimulus currents and gradient-based activation functions with threshold terms.
